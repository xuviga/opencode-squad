# SQUAD 0.9.6

The allowlist now holds without git too — and says so when it cannot.

## Attribution beats advice

0.9.5 enforced `paths` only in worktree missions: there the diff belongs to one
worker. In `isolation:"none"` the diff is a folder-wide snapshot, so a changed
file could be anyone's.

Every task's allowlist is now used to attribute that diff:

- a file that matches this task's `paths` is **mine**;
- a file a *concurrent* sibling claims is **theirs** (event
  `task.scope_siblings`);
- a file nobody claims is **unclaimed** — this worker wrote it, and
  `squad_wait` fails the task with `task.scope_violation`.

That is the guarantee people actually asked for: a worker cannot quietly ship a
file it did not declare.

## When the guarantee is weaker, the plugin says so

Attribution is only sound when every concurrent writer declared paths. If a
running sibling has no `paths`, the plugin emits `task.scope_unverifiable` and
treats the allowlist as advisory instead of pretending. A false pass is worse
than a stated limit.
