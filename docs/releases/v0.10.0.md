# SQUAD 0.10.0

Five items that were on the roadmap, closed together. This is the first release
where the plugin configures itself, guards its own folder and reports what it
cost.

## Write locks

In `isolation: "none"` two tasks with overlapping `paths` overwrote each other
and the reviewer saw a diff nobody could attribute. `squad_assign` now refuses
the second assignment with the conflicting task and the overlapping patterns.

Overlap is conservative: exact paths and `docs/` prefixes are compared
directly, a glob is reduced to its literal prefix and treated as overlapping
anything that shares it. Refusing a safe assignment is cheaper than two workers
fighting over a file. `squad_tasks` lists the active locks.

## A configuration file

`.squad/config.json` merges over the defaults: `maxRework`, `softWarnPct`,
`hardLimitUsd`, `staleAfterMinutes`, `gcIntervalMinutes`, `gcAutoAbort` and
per-grade model overrides. Unknown keys are ignored, so a newer file still
opens in an older plugin.

A broken file aborts plugin load with the field name. A typo in a budget should
not silently run the mission on defaults.

## A scheduled janitor

Every `gcIntervalMinutes` the plugin scans for missions idle past
`staleAfterMinutes`, writes a `gc.stale` event for each and logs one warning.
It aborts only when `gcAutoAbort: true`, and records `gc.auto_abort` when it
does. `gcIntervalMinutes: 0` disables the scheduler.

The default is report-only on purpose: an automatic abort destroys work.

## Budget and metrics in the panel

The `/squad` panel now prints pass@1, rework rate and cost per integrated task
from `tuiState.metrics`, next to the existing cost line.

## Image generation that works everywhere

`squad_image` defaults to `engine:"auto"`: an image model when one is
configured, the SVG→PNG vector path otherwise — and as a fallback when the
image model fails, with `fallback_reason` in the payload. `engine:"api"` now
fails with a message that names the alternative instead of an empty registry
error.

## Upgrade

Pull, add `.squad/config.json` if you want non-default limits, and restart the
host. No migration.
